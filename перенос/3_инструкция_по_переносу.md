# Перенос на другой компьютер

Система состоит из двух частей, и переносятся они по-разному:

| Часть | Что внутри | Как переносить |
|---|---|---|
| **Код** | программа, шаблоны, скрипты, тесты, эти инструкции | через git (GitHub) |
| **Данные** | папка `data\`: база и модели нейросети | вручную, защищённым способом, **не через git** |
| **Секреты** | файл `.env`: пароли и ключи | вручную, отдельно от данных, **не через git** |
| **Материалы задачи** (необязательно) | папка `materials\`: фид Softline и выгрузка чатов | вручную, если нужно пересоздать базу с нуля |

Почему данные не в git: в базе реальные (обезличенные) обращения клиентов, карточки клиентов и диалоги.
К тому же база весит 156 МБ, а модели — 228 МБ.

## 1. Требования к новому компьютеру

- Windows 10/11, Linux или macOS.
- Python 3.10 или новее. В Windows при установке отметьте «Add python.exe to PATH».
- Git.
- 2 ГБ свободного места, плюс 1,5 ГБ, если ставить нейросеть.
- Интернет на время установки: пакеты Python и, если не копировать модели, загрузка нейросети (119 МБ).
- Желательно путь к проекту без пробелов. Кириллица в пути работает, но некоторые утилиты с ней капризничают.

## 2. На старом компьютере: подготовить данные

1. Остановите сервер: Ctrl+C в окне, где он запущен. Иначе последние изменения могут остаться в служебных
   файлах `store_agent.sqlite3-wal` и `-shm` и не попасть в копию.
2. Упакуйте данные:

   ```powershell
   Compress-Archive -Path data\store_agent.sqlite3, data\models -DestinationPath agent-data.zip
   ```

   Модели (`data\models`, 228 МБ) копировать необязательно: на новом компьютере их можно скачать и дообучить
   заново, это 10–15 минут (шаг 5). Файл `data\consultant.sqlite3` — старая пустая база, она не нужна.
3. Скопируйте `.env`, если он есть. Это отдельный файл с паролями, передавайте его отдельно от архива.
4. Передайте архив защищённым способом: зашифрованная флешка, архив с паролем или корпоративное хранилище.
   В нём персональные данные клиентов (152-ФЗ). Не отправляйте его в открытые мессенджеры и в git.

## 4. На новом компьютере: данные и секреты

1. Распакуйте архив в папку проекта, чтобы получилось `agent\data\store_agent.sqlite3` и `agent\data\models\`:

   ```powershell
   Expand-Archive agent-data.zip -DestinationPath data
   ```

2. Положите `.env` в корень проекта, рядом с `run.py`. Если его не было, создайте из шаблона и задайте пароли
   (см. `4_роли_права_пароли.md`):

   ```powershell
   Copy-Item .env.example .env
   ```

3. Если хотите хранить данные в другом месте, например на отдельном диске, укажите это в `.env`:
   `DATA_DIR=D:\agent-data` и `MODELS_DIR=D:\agent-data\models`.

## 5. Если модели не скопированы

Пропустите этот шаг, если перенесли `data\models` целиком.

```powershell
.venv\Scripts\python scripts\download_model.py
```

```powershell
.venv\Scripts\python scripts\train_neural.py
```

Первая команда скачивает базовую модель (119 МБ). Вторая дообучает её на ваших обращениях, 5–10 минут на
процессоре. Можно не запускать вторую: сервер сам дообучит нейросеть в фоне при первом запуске.

## 6. Если базы нет и нужно собрать её заново

Нужна папка `materials\drive\` с материалами задачи (`Mindbox.yml.gz.xml`, `chats\buy_part_*_masked.txt`).

1. Запустите сервер (шаг 7), чтобы создалась пустая база с демо-данными.
2. Загрузите каталог, около 2,5 минут:

   ```powershell
   .venv\Scripts\python scripts\import_feed.py materials\drive\Mindbox.yml.gz.xml
   ```

3. В панели: «Переписки поддержки» → «Загрузить переписки» → выберите три файла `buy_part_*_masked.txt`.
4. Настройки, реквизиты для КП, база знаний и исправления классификатора в этом случае будут исходными.
   Всё, что меняли менеджеры, хранится только в старой базе.

## 8. Чтобы сервер работал постоянно

**Доступ с других компьютеров сети.** В `.env` укажите `HOST=0.0.0.0` и `PUBLIC_BASE_URL=http://<имя или IP сервера>:8000`
и откройте порт 8000 в брандмауэре. Для доступа из интернета ставьте сервер за HTTPS-прокси
(nginx, IIS, Caddy) и ограничьте `WIDGET_ALLOWED_ORIGINS` адресом сайта магазина.

**Windows: автозапуск.** Планировщик заданий → «Создать задачу»:
- триггер «При запуске системы»;
- действие — программа `C:\...\agent\.venv\Scripts\python.exe`, аргументы `run.py`, рабочая папка `C:\...\agent`;
- галочка «Выполнять для всех пользователей».

**Linux: служба systemd** (`/etc/systemd/system/agent.service`):

```ini
[Unit]
Description=Агент поддержки магазина ПО
After=network.target

[Service]
WorkingDirectory=/opt/agent
ExecStart=/opt/agent/.venv/bin/python run.py
Restart=always
User=agent

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now agent
```

## 9. Резервные копии

Достаточно копировать папку `data\` (база и модели) и файл `.env`. Делайте копию при остановленном сервере
или используйте встроенную команду SQLite, она работает и на запущенном:

```powershell
.venv\Scripts\python -c "import sqlite3; s=sqlite3.connect('data/store_agent.sqlite3'); d=sqlite3.connect('backup.sqlite3'); s.backup(d)"
```

## 10. Частые проблемы

| Проблема | Решение |
|---|---|
| `python` не найден | Переустановите Python с галочкой «Add to PATH» или используйте `py -3`. |
| Порт 8000 занят | Укажите в `.env` другой `PORT`, например 8080. |
| Первые 1–2 минуты страницы открываются медленно | Сервер обучает классификатор при запуске, это нормально. |
| Кракозябры в консоли | Сервер сам переключает консоль на UTF-8. Для скриптов: `$env:PYTHONIOENCODING="utf-8"`. |
| «Нейросеть не установлена» на странице классификатора | Шаг 3 (requirements-ml) и шаг 5 (download_model). Без неё всё работает, точность ниже на 2–3 п.п. |
| После обновления не видно изменений | Ctrl+F5 в браузере. |
