Коротко о переносе:

1. **Код** — из GitHub: `git clone`, затем `pip install -r requirements.txt`.
2. **Данные** (`data\`: база и модели) — архивом, защищённым способом. В git их нет, в базе персональные данные.
3. **Пароли** (`.env`) — отдельно от данных. В git их нет, в инструкциях только описание.
4. Запуск: `.venv\Scripts\python run.py`, проверка по списку в разделе 7 инструкции по переносу.
