# Инструкция разработчика

Агент поддержки магазина ПО: чат-консультант для покупателей, панель менеджера и классификатор обращений.
Прототип для хакатона ИИкузница, трек «Клиентские сценарии», задача Softline.

## 1. Стек

| Что | Чем сделано |
|---|---|
| Язык | Python 3.10+ |
| Веб | FastAPI + Uvicorn, шаблоны Jinja2, без фронтенд-сборки (чистые HTML/CSS/JS) |
| База | SQLite (один файл `data/store_agent.sqlite3`, режим WAL), полнотекстовый поиск FTS5 |
| Поиск и ML | scikit-learn (TF-IDF, логистическая регрессия, наивный Байес) |
| Нейросеть (необязательно) | PyTorch CPU + transformers, модель `cointegrated/rubert-tiny2` |
| Ассистент | по умолчанию — внутренние модели: правила, поиск, классификатор и нейросеть; необязательный ИИ-режим — языковая модель по API (ключ `LLM_API_KEY`) |
| Документы | python-docx (КП и счёт в DOCX), HTML для печати и PDF |
| Импорт | openpyxl (XLSX), потоковый разбор XML-фидов |
| Тесты | pytest (46 тестов) |

Нейросеть для классификатора необязательна. Без неё классификатор работает на TF-IDF-модели, точность ниже на 2–3 п.п.:

```powershell
.venv\Scripts\pip install -r requirements-ml.txt
```

```powershell
.venv\Scripts\python scripts\download_model.py
```

Запуск:

```powershell
.venv\Scripts\python run.py
```

- Витрина с чат-виджетом: http://127.0.0.1:8000/demo
- Панель менеджера: http://127.0.0.1:8000/admin
- Документация API: http://127.0.0.1:8000/api/docs

При первом запуске на пустой базе загружаются демо-данные: около 60 товаров, статьи базы знаний и примеры обращений.
Настоящие данные загружаются отдельно (см. раздел 6).

В Linux и macOS вместо `.venv\Scripts\` пишите `.venv/bin/`.

## 4. Как устроена обработка обращения

1. Клиент пишет в виджете (`POST /api/chat/{id}/messages`), письмом или через интеграцию (`POST /api/channels/inbound`).
2. `engine.handle_client_message` сохраняет сообщение и вызывает классификатор (`classifier.classify_dialog`):
   тип обращения и IT-тема записываются в диалог.
3. Отвечает ассистент. По умолчанию это офлайн-ассистент на внутренних моделях: правила, поиск по каталогу
   и базе знаний. Если задан `LLM_API_KEY`, включается ИИ-режим: языковая модель вызывает те же инструменты из
   `tools.py` и сама решает, что спросить. При сбое API диалог подхватывает офлайн-ассистент.
4. Бизнес-ограничения заложены в коде, а не в промпте. Скидку больше 5% даёт только менеджер. Оплата только
   предоплатой. КП создаётся черновиком и уходит клиенту после утверждения менеджером.
5. Если нужен человек, диалог попадает на доску «Ждут решения» с таймером 2 минуты, менеджеру уходит уведомление.

## 5. Классификатор обращений

- Две «головы»: **тип обращения** (9 категорий разметки чатов Softline) и **IT-тема** (справочник ключевых слов).
- Алгоритм по умолчанию — `hybrid`: 70% TF-IDF-модель (слова и символьные n-граммы, логистическая регрессия)
  и 30% дообученная rubert-tiny2. Ключевые слова справочника важнее модели.
- Ниже 80% уверенности обращение попадает в очередь «На проверку». Подтверждение или исправление
  менеджера становится обучающим примером. TF-IDF-модель переобучается сразу, нейросеть — в фоне,
  когда накопится 30 новых примеров.
- Модели хранятся в `data/models/`. Указатель на действующую версию — файл `request_type-rubert.current`.
  Новая версия включается заменой указателя: Windows не даёт перезаписать файлы загруженной модели.
- Точность на 495 чатах: 75,6% по исходной разметке и 78% по проверенной. Подробности — в README,
  раздел «Классификатор», и в отчёте `scripts/evaluate_classifier.py`.

## 6. Служебные скрипты

| Скрипт | Зачем |
|---|---|
| `scripts\import_feed.py <файл>` | загрузить большой товарный фид (136 тыс. офферов — около 2,5 мин) |
| `scripts\evaluate_chats.py <папка с чатами>` | прогнать ассистента по реальным обращениям, отчёт в `reports/` |
| `scripts\evaluate_classifier.py [--neural] [--original]` | оценить классификатор кросс-валидацией |
| `scripts\download_model.py` | скачать rubert-tiny2 (119 МБ) |
| `scripts\train_neural.py` | дообучить нейросеть синхронно, с прогрессом |
| `scripts\bench_search.py 200000` | нагрузочная проверка поиска |

Загрузка реальных материалов задачи. Файлы с Google Диска организаторов кладутся в `materials\drive\`:

```powershell
.venv\Scripts\python scripts\import_feed.py materials\drive\Mindbox.yml.gz.xml
```

Переписки загружаются в панели: «Переписки поддержки» → «Загрузить переписки» (`buy_part_*_masked.txt`).

## 7. Тесты

```powershell
.venv\Scripts\python -m pytest -q
```

Тесты работают на временной базе и без нейросети (`MODELS_DIR` указывает во временную папку), поэтому
занимают 1–2 минуты и не трогают рабочие данные.

## 8. Настройки (.env)

Скопируйте `.env.example` в `.env` и заполните нужное. Все параметры необязательны.

| Переменная | Значение |
|---|---|
| `HOST`, `PORT` | адрес сервера, по умолчанию 127.0.0.1:8000 |
| `PUBLIC_BASE_URL` | внешний адрес, используется в ссылках на КП и счета |
| `DATA_DIR`, `MODELS_DIR` | где лежат база и модели, по умолчанию `data/` и `data/models/` |
| `SECRET_KEY`, `ADMIN_PASSWORD`, `INTEGRATION_TOKEN` | секреты, см. `4_роли_права_пароли.md` |
| `WIDGET_ALLOWED_ORIGINS` | с каких сайтов разрешён виджет, через запятую |
| `LLM_API_KEY`, `LLM_EFFORT`, `LLM_FALLBACKS`, `LLM_DISABLED` | необязательный ИИ-режим (языковая модель по API) |
| `EMAIL_*` | почтовый канал (IMAP входящие, SMTP исходящие) |
| `TELEGRAM_BOT_TOKEN` | Telegram-бот для клиентов |
| `MANAGER_TELEGRAM_CHAT_ID`, `MANAGER_EMAIL` | куда слать уведомления менеджерам |

Настройки бизнеса (реквизиты для КП, цены и скидки, SLA, нормативы экономики, порог классификатора)
хранятся в базе и правятся в панели: «Настройки» и «Классификатор → Модель и обучение».

## 9. Что учесть при доработке

- Схема базы меняется через `db.py`: новые таблицы — в `SCHEMA`, новые колонки — в `MIGRATIONS`.
  Существующие базы обновляются при запуске.
- Шаблоны Jinja2 кешируются, после правки шаблона перезапустите сервер. Стили и виджет подключаются с
  версией по времени изменения файла, браузер подхватит их сам.
- Данные клиентов и выгрузки чатов (`data/`, `materials/`, `reports/`) в git не попадают и не должны попадать.
- Перед коммитом запускайте тесты.
